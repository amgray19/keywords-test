Keyword Search Tool

Scans .docx, .pdf, and plain-text documents for contested vocabulary and reports every sentence a term appears in, with suggested alternatives and a frequency chart. A default list of 734 terms drawn from federal funding language is pre-loaded; upload or paste your own to scan for anything else.

📘 About This Tool (Click to Expand)

✨ Features

  • Fully client-side processing (no files ever leave your computer)
  • Reads Word (.docx), PDF, and plain text
  • Scans several documents as one submission
  • 734-term default list, or upload/paste your own
  • Download a sample keywords.txt for testing
  • Bar and pie chart visualization
  • A Terms to Use tab of vocabulary agencies are rewarding
  • Dark/light mode toggle
  • Strict Content Security Policy for security

🛡️ Security

This tool is 100% client-side.

  • Uploaded files are processed in your browser.
  • No file content is sent to any server.
  • Strict Content Security Policy prevents injection.
  • Document text is escaped before display, so a booby-trapped file cannot run code.

🚀 Usage

  1. Upload a .txt file of keywords (or paste keywords into the textarea).
  2. If you don't have a list, download the sample keywords.txt.
  3. Upload one or more .docx, .pdf, or .txt files.
  4. Click Generate Summary.
  5. Review results and charts.
  6. Use Print or Save Summary to export a report.

Terms to Use

Vocabulary federal agencies are actively rewarding, compiled from executive orders, OMB guidance, and agency program language. These are the words that make a proposal read as aligned with what the government is funding now. Ranked by how often each term appears in the harvested federal corpus, so the most established language sits at the top.

Mention counts come from the most recent harvest of federal documents and indicate how established a term already is, not how fast it is growing. A term with few mentions is newer language, not weaker language. Verify against the primary source before building an argument on any single term.
